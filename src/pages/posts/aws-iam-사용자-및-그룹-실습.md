* IAM 첫 입장시 해당 대시보드 
* 보안 권장 사항은 이 후에 설정
* 왼쪽 탭의 사용자 선택

![user](/uploads/스크린샷-2026-03-11-오후-2.34.18.png "user")

* 해당 탭에서 사용자를 생성
* 여기서 확인해야하는 점은 오른쪽 상단을 보면 글로벌이 보임
* 해당 글로벌 선택시 리전 선택이 활성화 되지 않는 것을 볼 수 있음
* 즉 IAM 서비스는 전체 서비스로 글로벌 서비스에 해당함(선택할 리전이 없음)
* 루트 계정이어야  생성가능



## 사용자 생성 단계

1. 사용자 생성 버튼 클릭
2. 사용자 세부 정보 지정

   * 사용자 이름
   * AWS Management Console 액세스 권한 제공 설정
   * 체크하게 되면 콘솔 암호 설정

     * 보통 본인이 아닌 다른사람에게 전달할 경우 자동 생성된 암호를 발급 받아 아이디와 해당 비밀번호 전달후 비밀번호 변경 하는 방식 선호
     * 본인이 쓸 것이면 바로 사용자 지정 암호 구성해도됨(이때 밑에 사용자는 다음 로그인 시 새암호를 생성해야 합니다 체크 해제)
3. 권한 설정 (개인 설정도 가능하고 그룹별로 설정도 가능하다)

   * 권한옵션
   * 그룹 시작하기(그룹 생성)

     * 그룹 생성 버튼 클릭
     * 사용자 그룹 생성 탭 에서 사용자 그룹 이름 설정(예 : admin)
     * 정책 이름(테스트용으로 Administrator Access)
     * 생성하기 버튼 클릭
   * 권한 경계 설정 - 선택 사항
4. 검토 및 생성

   * 사용자 세부 정보
   * 권한 요약
   * 태그 - 선택사항 (리소스 식별시 유용)
5. 암호 검색

   * 콘솔 로그인 세부 정보

     * 콘솔 로그인 URL 
     * 사용자 이름
     * 콘솔 암호 

일련의 과정을 수행하고 나면 생성이 완료.
